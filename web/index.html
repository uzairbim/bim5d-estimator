Estimate cost straight from your BIM model

Upload an IFC file from Revit. Every element is measured from its 3D shape, broken into work items, priced with your rates, and shown on the model.

1Pick your country. Prices are ready (assumed) and you can change any of them.
2Drop your Revit model exported as IFC, or try the demo.

How to export IFC from Revit
  1. In Revit: File → Export → IFC.
  2. IFC version: IFC 2x3 Coordination View 2.0 or IFC4 Reference View.
  3. On the Property Sets tab, tick Export Revit property sets and Export base quantities.
  4. Optional: set an Assembly Code (Uniformat) on your types, which helps automatic classification.
  5. Upload the .ifc file here. Large models take a minute the first time; after that they open instantly.

Quick start

  1. Region: pick your country on the start page. Saudi Arabia, UAE, Pakistan, India, UK, Germany and USA have assumed prices ready. For another country: Add my country / prices.
  2. Model: in Revit, File > Export > IFC (IFC 2x3 Coordination View 2.0). Drop the .ifc file on the start page.
  3. What to do next: the box at the top of the Summary lists the few actions that improve the estimate most. Do them in order.
  4. Report: Client report opens a printable PDF; Export Excel gives the full workbook.

Words used in the app

BOQ
Bill of quantities: every work item with its quantity, rate and amount.
Work item
A priced piece of work, e.g. "Concrete block wall, m²".
Recipe
How one model element becomes work items, e.g. a block wall gives blockwork, plaster and paint.
Rate build-up
A rate made from resources: labour hours × wage + materials × price + plant. Click any item in Prices & rates to see it.
Assumed price
A typical market price (late 2026) shipped with the app. Prices change daily; type today's price over it.
Estimated price
A price converted from US levels with the country's factors. Least reliable; replace first.
Allowance
A sum for work that is not in the model, e.g. MEP 25% of measured work.
Preliminaries
Site costs not tied to one item: site staff, offices, scaffolding, temporary works, insurance.
Contingency
A reserve for unknowns and design changes.
Accuracy class
How close the final cost is likely to be (AACE guidance): Class 5 −50%/+100%, Class 4 −30%/+50%, Class 3 −20%/+30%, Class 2 −15%/+20%.
NRM1 / Uniformat
Standard ways to group cost by building element (substructure, frame, roof…).
Overlap
Where two elements occupy the same space (column through slab). Counted once.
Reconciliation
Our measured volumes compared with Revit's own values, to catch measurement problems.

Common questions

Why is the cost per m² lower than usual?
Usually parts of the building are not in the model (MEP, external works). Look at the Scope check and add the suggested allowances.
Some elements are not priced.
Open Mapping and choose what each type is. Every element of that type follows.
A quantity looks wrong.
Click the element in 3D: you see the measured quantities, the formula and Revit's own volume. You can adjust a type's quantity with a written reason.
Furniture is not in the total.
Loose furniture is normally the client's separate budget. Built-in joinery is included. Tick "Include loose furniture" in Project settings if you need it.
How do I send a project to a colleague?
Project settings > Download project file. They use "Open a project file" on the start page.
How do I share prices?
Prices & rates > Region & sharing > Download rate pack.
Structure and MEP are separate Revit models.
Open the architecture project, go to Compare, choose the discipline and click "Add a discipline model". The estimate adds them up; elements drawn in two models are counted once.
Which files can I upload?
.ifc, .ifcZIP (Revit: File > Export > IFC, tick "Save as .ifcZIP") or a zip with the .ifc inside. IFC 2x3, IFC4 and IFC4.3 all work.
Can I get the BOQ in Arabic?
Choose العربية at the top. For Saudi Arabia and other Arab countries the Excel BOQ has Arabic columns, and the client report follows the language.
I need a BOQ to send to contractors.
Export Excel, sheet "Priced BOQ": numbered bills, quantity × rate formulas, bill summary with VAT. Change a rate in Excel and the totals update.
The cost per m² range does not fit my building.
Project settings > Building type (villa, office, school, mosque, hotel, hospital, warehouse…).
Is there a Saudi example?
Start page > samples > Saudi Villa Example: footings, tie beams, hordi roof, thermal block, marble, Arabic room names.
