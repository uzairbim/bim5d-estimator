Upload an IFC file from Revit. Every element is measured from its 3D shape, broken into work items, priced with your rates, and shown on the model.

How to export IFC from Revit
  1. In Revit: File → Export → IFC.
  2. IFC version: IFC 2x3 Coordination View 2.0 or IFC4 Reference View.
  3. On the Property Sets tab, tick Export Revit property sets and Export base quantities.
  4. Optional: set an Assembly Code (Uniformat) on your types, which helps automatic classification.
  5. Upload the .ifc file here. Large models take a minute the first time; after that they open instantly.
