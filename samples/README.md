# Sample models

Public IFC sample files used to test the estimator (from the `youshengCode/IfcSampleFiles`
collection of well-known Revit / buildingSMART samples). Check their original licences
before redistributing them.

| File | What it shows |
|---|---|
| Ifc2x3_Duplex_Architecture.ifc | Small Revit house, walls with material layers |
| Ifc2x3_Duplex_Architecture_Rev2.ifc | Same model edited (2 doors and 4 cabinets removed, 1 wall added, ground slab thicker). Loaded automatically as "Rev 2" to demo revision comparison. |
| Ifc4_SampleHouse.ifc | IFC4 house with layered floors and curtain wall |
| Ifc4_Revit_ARC.ifc | Larger Revit architectural model with appliances, entourage and proxies |
| Ifc4_Revit_STR.ifc | Revit structural model with 3,680 modelled rebar bars |
| Ifc4_Revit_MEP.ifc | Revit MEP model (ducts, pipes, fittings, lights, sprinklers), German names |
| Ifc2x3_Duplex_MEP.ifc | IFC2x3 MEP model using generic flow classes |
